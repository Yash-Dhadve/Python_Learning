# Introduction to Python

## Definition
Python is a high-level, interpreted, general-purpose programming language designed for readability, developer productivity, and rapid application development.

## Explanation
Python emphasizes clear syntax, dynamic typing, built-in data structures, and a rich standard library. It is widely used for scripting, automation, web development, data science, and machine learning.

## Internal Working
CPython parses source code into an Abstract Syntax Tree (AST), compiles it to bytecode, and executes it on the Python Virtual Machine (PVM). Memory management is handled by reference counting and a cyclic garbage collector.

## Syntax
```python
name = 'Alice'
print(f'Hello, {name}')
```

## Parameters
N/A for language definition; Python constructs accept arguments per syntax rules.

## Return Values
Python functions return values using the `return` keyword. Expressions produce objects that can be assigned or passed to functions.

## Example
```python
def greet(name: str) -> str:
    return f'Hello, {name}'

print(greet('Alice'))
```

## Output
```
Hello, Alice
```

## Python Features
- Interpreted language
- Dynamic typing
- Automatic memory management
- Batteries-included standard library
- Multiple programming styles (procedural, OOP, functional)
- Extensible with C/C++ modules

## Python Architecture
Python source is parsed into tokens, then into an AST. The AST is compiled into bytecode which the PVM executes. Modules are cached in `sys.modules` for fast reuse.

## Bytecode
Bytecode is a lower-level, platform-independent representation of Python code. CPython writes compiled bytecode to `.pyc` files in `__pycache__`.

## PVM
The Python Virtual Machine executes bytecode. It maintains a frame stack, dispatches bytecode instructions, and manages exceptions.

## CPython vs PyPy
CPython is the reference implementation written in C, offering the broadest compatibility. PyPy is an alternative implementation with a JIT compiler designed for higher performance in some long-running workloads.

## GIL Introduction
The Global Interpreter Lock (GIL) in CPython ensures only one thread executes Python bytecode at a time. It simplifies memory safety but limits parallel CPU execution.

## Memory Overview
Python uses a heap for object allocation and a stack for execution frames. Objects are tracked by reference counts and cleaned by a garbage collector for cycles.

## Coding Exercises
### Exercise 1: Print first 10 Fibonacci numbers
```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        print(a)
        a, b = b, a + b

fib(10)
```

### Exercise 2: Count lines in a text file
```python
def count_lines(path):
    with open(path, encoding="utf-8") as file:
        return sum(1 for _ in file)

```

### Exercise 3: Check if a number is even
```python

    return n % 2 == 0

```
